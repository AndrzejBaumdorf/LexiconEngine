# LexiconEngine
完全自分用語彙力トレーニングエンジン

## 現在できること

- 単語、言語、品詞、複数の語義、例文、類義語・対義語、出典、難易度をSQLiteに保存
- 英→日、日→英、例文穴埋め、類義語・対義語、派生語の4択問題 (選択肢は同じ言語の単語から作る)
- ドイツ語名詞の性・複数形 (意味ごと)、派生語の登録
- ドイツ語の格支配クイズ (入力式): 格支配の穴を持つ例文 (`materials/German/A1A2_単語集/valency.ai.json`、AI生成) の穴に、格変化させた句を入力する。例: `Wir holen Anna ___ ab. (die Schule)` → `von der Schule`。前置詞と冠詞の融合形・融合しない形 (`am Tisch` / `an dem Tisch`) はどちらも正解。例文は取り込み時に、穴の句がヒントの名詞から作った正しい格変化と一致するかを検証し、合わないものは取り込まない。例文のない意味は出題しない
- ドイツ語の活用クイズ (入力式): `ab|fahren 出発する ｜ du・現在 → ___` に `fährst ab` を入力する。現在形・過去形・現在完了の全人称を、登録した3人称単数現在・過去・現在完了から作る (分離動詞は前つづり、再帰動詞は再帰代名詞も入力。先頭に主語を付けて答えてもよい)。規則で決まらない形 (halten の du など) や sein・haben・話法の助動詞は出題しない。3つの形が登録されていない動詞は出ない。出題は 動詞の誤り率 × 人称の誤り率 × 時制の誤り率 に比例させ (誤り率は (誤答+1)/(回答+2)、重みには下限あり)、セットの開始時と、その後50問ごとに回答履歴から計算し直し、その間は固定する。苦手な人称・時制は動詞を変えて練習される。人称 × 時制の正答率は単語一覧の「活用の正答率」で見られる
- ドイツ語名詞の性 (der/die/das) クイズと複数形クイズ (複数形は誤った形を見せないよう選択肢を出さずに入力させる。ä/ö/ü/ß は入力欄の横のボタンで入れられ、先頭の die や大文字・小文字の違いは無視する。複数形が `-` の語は出題しない)
- 韓国語のラテン文字転写テスト (国語のローマ字表記法。連音化・鼻音化・流音化・激音化・口蓋音化を反映し、誤答は音変化を無視した転写や字母の取り違えから作る)
- 問題形式ごとの回答履歴と直近10問の正答率
- JSONと照合 (クイズ画面の「JSONと照合」): 選んだフォルダ (とサンプル) のJSONをすべて取り込み直した状態とDBを比べ、消える・増える単語・見出し・意味・例文を確認してから、DBの単語データをJSONに合わせる。JSONを直したのにDBに残った古い意味や、JSONから消した単語を片付ける。回答履歴は同じ単語に付け替える。回答履歴のある消える単語は、確認画面で意味が増える単語から引き継ぎ先を選べる (綴りを直した単語 (anntotate → annotate のようによく似た綴りの1対1の組) は最初から選ばれている)。引き継がない単語の回答履歴は消える
- 単語一覧 (クイズ画面の「単語一覧」): 単語ごとの品詞・意味・誤答スコア・正解/回答数・最終回答日時・出典を表にし、列見出しのクリックで並べ替え (初期は意味の誤答スコアの高い順)。行は並べ替えている集計単位の誤答スコアで色分けする (0.5 以上は赤、0.2 以上は橙、未回答は灰色)。問題形式・検索・回答済みのみで絞り込める
- 直近の不正解を重くするpriority出題。開始画面の「出題モード」で使うスコアを選ぶ。既定は未習得スコアで、誤答スコアは最近間違えた単語だけを見直したいとき用 (どちらも直近25回の正誤を、新しい順に n = 0, 1, 2 … として 0.841ⁿ で重み付けする。出題確率は 1 + 5 × スコア に比例。活用クイズは別の方式)
  - 誤答スコア: Σ(誤答 × 0.841ⁿ) / Σ0.841ⁿ を答えた回だけで計算する。最近間違えた単語が出やすい。未回答は 0。単語一覧の色分け・並べ替えもこのスコア
  - 未習得スコア: 25回に満たない分を誤答として数え、n = 0〜24 の全25回で計算する。未回答は 1、25回続けて正解すると 0 で、未回答や回答の少ない単語も出やすい
- JSONから単語データを構造化して取り込み

## 起動

```powershell
py src/main.py
```

DBを作り直すときは `--reset` を付けます。確認のあと、元のDBは `data/lexicon-backup-<日時>.db` に名前を変えて残し、空のDBから起動します (`-y` で確認を省略)。教材は「フォルダ取り込み」で入れ直してください。

```powershell
py src/main.py --reset
```

言語・出典・レベル・問題形式・出題数を選んで開始します。言語はDBに登録されている言語から選び、出題・選択肢・直近の正答率はその言語の単語だけで扱います。出典 (`source`)・レベル (`difficulty`)・品詞・取り込んだJSONファイル (教材フォルダからの相対パス) で出題する単語を絞り込めます (それぞれ複数選択可、未選択ならすべて)。派生語 (`derivatives`) は派生元の見出し語と同じ出典・レベル・ファイルとして扱います。ファイルの一覧は取り込んだときに記録するので、このバージョンより前に取り込んだファイルは、取り込み直すか「JSONと照合」をすると出ます。誤答の選択肢は範囲を絞っても同じ言語の単語全体から選びます。問題形式名は言語に合わせて「英→日」「独→日」のように変わります。「ラテン文字転写」(韓国語)、「性 (冠詞)」「複数形」(ドイツ語) は対応した言語を選んだときだけ表示されます。

英語の例文穴埋めで穴の語が活用形 (petrified, accolades など) のときは、選択肢も同じ形 (過去形・過去分詞・-s・-ing) にそろえます。不規則動詞は `src/english.py` の表で活用させます (over- などの接頭辞付きにも対応)。

クイズ中のショートカット: `1`〜`4` 選択肢を選ぶ / `Enter` 回答・次の問題へ / `S` スキップ (不正解として記録) / `Esc` 中断。新しくDBを作ると `samples/sample_words.json` が取り込まれます。

教材データは `materials/` に置いてください。このディレクトリとDBはGit管理対象外です。`言語/本/ファイル` の形で整理し、AI生成の補足 (`"source": "AI generated"`) は元のファイルの横に `.ai.json` で置きます。

```
materials/
├── English/
│   └── JapanTimes_EX/
│       ├── unit01.json
│       ├── unit01.ai.json      ← unit01 の単語の AI 生成例文
│       └── unit02.json
├── German/
│   └── A1A2_単語集/
│       ├── A_A1.json
│       ├── basic/
│       │   └── basic_time.json
│       └── valency.ai.json     ← 格支配クイズ用の AI 生成例文
└── Korean/
    └── basic_korean_300.ai.json
```

- 出典 (`source`) はフォルダ名からではなく、各見出しの `source` から決まります (ファイルを移しても出典は変わらない)。ファイルを移したり名前を変えたりしたら「JSONと照合」でDBに反映します
- 出題範囲の「ファイル」ではフォルダ (`English/JapanTimes_EX/` など) も選べ、その下のファイルすべてが範囲になります
- エディタの保存先にはサブフォルダ内のJSONも一覧に出ます。`German/白水社/B.json` のように存在しないパスを入力すると、フォルダごと新しく作ります。
- 一番上のフォルダ名が言語名 (English / German) のとき、空のファイルを開くと言語の初期値がそのフォルダ名になります。
- クイズ画面の「フォルダ取り込み」で、選んだフォルダ以下のJSONをまとめてDBに取り込めます。

## iPad などのブラウザ版 (Mac と同期)

iPad のブラウザ (ホーム画面に追加して使う) でクイズ・単語一覧・単語編集を使えます。DB と教材JSONの写しを iPad の中に持つのでオフラインでも解けて編集でき、Mac と同じ Wi-Fi にいるときに「Macと同期」を押すと、回答履歴を足し合わせ、iPad での編集を Mac の教材JSONに反映して、単語データを Mac のものにそろえます。JSONの取り込み・JSONと照合は Mac (このアプリ) で行います。

- 中身: `web/` の画面が Pyodide (ブラウザ内の Python) で `src/` の database.py などをそのまま動かす。DB はブラウザの IndexedDB に保存する
- 同期: 回答ごとに一意なID (`answer_history.uid`) を付けてあり、互いにない回答を送り合う (単語は 見出し語×言語 で対応させる)。単語データは Mac の DB で置き換える (iPad の回答履歴は先に Mac へ送るので消えない)
- 単語編集: 入力欄はデスクトップ版のエディタと同じ (品詞ごとの語形・格支配・類義語・例文の [ ] など)。保存すると iPad のDBにもすぐ反映され、「未同期の編集」として記録される。同期で Mac の教材JSONに反映し、Mac の DB も「JSONと照合」と同じ方法で作り直す (綴りを直した単語の回答履歴は引き継ぐ)
- 競合: 同じ見出し (単語×言語×出典×レベル) を Mac と iPad の両方で変えていたときは、同期の画面で両方の中身を見て「iPad の版を残す / Mac の版を残す / あとで決める」を選ぶ。別々の見出しの編集は自動で両方反映する。同期中は Mac の単語エディタで同じファイルを開いたまま保存しないでください (iPad の編集を上書きしてしまう)
- 必要なもの: Flask (`pip install flask`)、mkcert (`brew install mkcert`)。初回の起動だけインターネット (Pyodide の取得) が必要

### 最初に1回だけ

1. Mac で `python src/server.py --setup-cert` を実行する (パスワードを聞かれます)。このMac用の HTTPS 証明書ができ、Finder で `rootCA.pem` が開く
2. `rootCA.pem` を iPad に AirDrop し、iPad の 設定 → 一般 → VPNとデバイス管理 でプロファイルをインストールする
3. iPad の 設定 → 一般 → 情報 → 証明書信頼設定 で mkcert の認証局をオンにする
4. Mac で `python src/server.py` を起動し、iPad の Safari で表示された `https://<Macの名前>.local:8443` を開く。共有ボタン →「ホーム画面に追加」
5. ホーム画面のアイコンから開いて「Macと同期」を押す (Safari のタブとホーム画面のアプリは保存場所が別なので、ホーム画面のアプリで同期する)

Mac のファイアウォールで Python への接続を聞かれたら許可してください。

### ふだん

- iPad はどこでも (オフラインでも) ホーム画面のアプリで解く
- 同期したいときに Mac で `python src/server.py` を起動し、同じ Wi-Fi で iPad の「Macと同期」を押す。Mac のアプリ (tkinter) を開いたままでもよい
- `src/` や `web/` を更新したときは、Mac のサーバーにつながった状態でアプリを開き直すと新しい版になる

## バックアップと安全装置

単語データや回答履歴が消える可能性のある操作の前に、自動でバックアップを取ります (`data/backups/`、新しいものから30個)。

- 「JSONと照合」の反映前と、iPad の編集を Mac に反映する前に DB を `lexicon-<日時>-<操作>.db` として保存する。クイズ画面の「バックアップから復元」で選んだバックアップに戻せる (戻す前の DB もバックアップする)
- iPad の編集で教材JSONを書き換える前に、そのファイルを `materials-<日時>-ipad-edits/` に保存する。戻すときはファイルを `materials/` にコピーし直す
- 「JSONと照合」で単語の1割以上 (または回答履歴のある単語) が消えるときは、確認画面の先頭に警告を出す (選ぶフォルダを間違えたときなど)
- iPad の編集を反映するとき、編集 (削除・綴りの修正) で説明できない単語が DB から消えそうなら、Mac の DB は作り直さずに編集したファイルだけを取り込み、iPad に警告を返す。確認は Mac の「JSONと照合」で行う
- iPad は、Mac から受け取った単語データや教材ファイルが手元より半分以上少ないときは置き換えない (Mac 側の事故を iPad に広げない)。置き換える前の iPad の DB も1つ残す

`materials/` は Git 管理の外なので、Time Machine や別のリポジトリなどでもバックアップしておくと安心です。

## GUIで単語登録・編集

```powershell
py src/word_editor.py
```

左の一覧から単語を選ぶと内容を読み込み、品詞・意味・例文などを編集して上書き保存できます。「新規」で新しい単語を入力し、保存すると `materials/` のJSONに下記の形式で追加されます。新規入力した単語が登録済みなら、品詞・意味単位で追記するか確認します。

- ショートカット (WindowsはCtrl): `⌘S` 保存 / `⌘N` 意味欄の内容を確定して次の意味へ (一覧で選んだ意味を編集中なら更新) / `⌘⇧N` 新しい単語
- 類義語・対義語は `forsake=見捨てる` のように意味も書くと英→日の出題にも使われます。
- 派生語は `placatory(形容詞)=なだめるような, placation(名詞)` の形で書きます。意味は省略できます。
- 語形の欄は言語と品詞に応じて表示されます。German の名詞では性 (m/f/n)・複数形、動詞では現在3人称単数・過去形・現在完了 (`hat gemacht` / `ist gegangen`) を入力します。der See / die See や hängen (hing / hängte) のように意味で変わる語があるため、意味ごとに設定します。登録した語形は例文穴埋めで穴にする語として使われ (現在完了は最後の語)、出題時は `das Haus (複数: Häuser)` `gehen (geht - ging - ist gegangen)` のように表示されます。
- 例文の穴埋め箇所は活用形 (petrified, abandoned, ドイツ語の語尾変化など) から自動で探します。見つからない不規則形は `They [overrode] it.` のように `[ ]` で囲みます。分離動詞は `Er [fängt] morgen [an].` のように複数囲めます。

DBへの反映はクイズ画面の「JSON取り込み」で行います。取り込みではJSONの内容を正とし、JSONから消した意味・例文・関連語はDBからも消えます。JSONから単語ごと削除した場合は、DB側には残ります。

## 言語ごとの仕様

品詞の候補、名詞の性と冠詞、品詞ごとの語形の欄 (`form_fields`)、例文穴埋めでの活用形の推測は `src/languages.py` に言語ごとにまとめています。新しい言語は `Language(...)` を定義して `LANGUAGES` に加えると、エディタの言語欄・品詞欄、穴埋め、出題時の冠詞表示に反映されます。未登録の言語名で登録した単語は、性なし・活用推測なし (例文中の完全一致か `[ ]` 指定のみ) で扱います。

## JSON形式

JSONは単語オブジェクト、または単語オブジェクトの配列にします。単語の下に品詞、品詞の下に意味を置きます。類義語・対義語は意味の下に置き、関連する単語・品詞・意味を指定します。

```json
[
	{
		"word": "abandon",
		"language": "English",
		"difficulty": "B2",
		"source": "The Japan Times EX",
		"parts_of_speech": [
			{
				"part_of_speech": "動詞",
				"meanings": [
					{
						"meaning_ja": "放棄する",
						"synonyms": [
							{
								"word": "forsake",
								"part_of_speech": "動詞",
								"meaning_ja": "見捨てる"
							}
						],
						"examples": [
							{
								"sentence": "They abandoned the plan.",
								"translation_ja": "彼らは計画を断念した。"
							}
						]
					}
				]
			}
		],
		"derivatives": [
			{
				"word": "abandonment",
				"part_of_speech": "名詞",
				"meaning_ja": "放棄"
			}
		]
	},
	{
		"word": "See",
		"language": "German",
		"parts_of_speech": [
			{
				"part_of_speech": "名詞",
				"meanings": [
					{ "meaning_ja": "湖", "gender": "m", "plural": "Seen" },
					{ "meaning_ja": "海", "gender": "f" }
				]
			}
		]
	},
	{
		"word": "gehen",
		"language": "German",
		"parts_of_speech": [
			{
				"part_of_speech": "動詞",
				"meanings": [
					{ "meaning_ja": "行く", "present_3sg": "geht", "past": "ging", "perfect": "ist gegangen" }
				]
			}
		]
	}
]
```

同じ単語が別の出典・レベルにも載っている場合 (A1 の接続詞 `aber` と A2 の心態詞 `aber` など) は、出典・レベルごとに別のエントリとして書けば、DBでは1つの単語にまとめて登録されます。取り込み時の更新・削除は同じ出典・レベルのエントリの範囲だけで行われ、出題の絞り込みは意味ごとに判定されます。

ドイツ語の分離動詞は見出し語に `"ab|fahren"` (再帰動詞なら `"sich an|melden"`) のように前つづりの後ろへ `|` を付けます。DBには `abfahren` として登録され、例文穴埋めでは離れた2か所 (`Wir fahren um 10 Uhr ab.` → `Wir _____ um 10 Uhr _____.`) や `abgefahren`・`abzufahren` も穴にでき、独→日の問題では `ab|fahren` と表示されます。`|` のない動詞は分離動詞として扱いません。

ドイツ語の格支配は意味ごとの `"valency": ["Akk", "von+Dat", "sich+Akk"]` に書きます。各要素は 格 (`Nom`/`Akk`/`Dat`/`Gen`)、前置詞+格 (`auf+Akk`)、`sich+格` のいずれかで、問題文と単語一覧では `ab|holen ［+ Akk, von + Dat］` のように表示されます。`meaning_ja` には格を書かず、括弧は `〈 〉` = 主語・目的語の制限 (`〈人〉をなだめる`)、`［ ］` = 文法の注記・用法の分類 (`［受動態］`、`［場所］`)、`（ ）` = 補足・決まった言い回し。決まった言い回しの中の見出し語は `-` で伏せる (`（im -で）特売中`、`（zur -で）アウトバーンへ`)。書き忘れても日→独の問題文と穴埋めのヒントでは自動で伏せる と使い分けます。単語エディタでは「格支配」欄に `Akk, von+Dat` と入力できます。

格支配クイズの例文は、例文に `"valency": {"slot": "von+Dat", "phrase": "vom Bahnhof", "hint": "der Bahnhof"}` を付けて書く。`hint` は穴の名詞の1格 (複数は `die Kinder (Pl.)`、冠詞のない語は `Japan`)、再帰代名詞の穴は主語 (`du`)。弱変化の疑いがある男性名詞はヒントに使えない。例文ファイルの意味には、教材と同じ活用形・格支配を写しておく (共有する意味の値が取り込み順で上書きされるため)

例文の `targets` は穴埋めにする語を本文中の出現順に並べたものです (エディタの `[ ]` から自動で作られます)。旧形式の `"related_words": {"noun": "tenacity"}` も派生語として取り込めます。
